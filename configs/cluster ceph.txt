### Настройка кластера Ceph ###

Для объектов (используются, RGW/S3). Для использования с RBD (блочные устройства) или CephFS (файловая система) 

Будет использоваться всего 3 сервера, на которых будут устанавливаться все роли. 
На всех хостах под ceph созданы отдельные диски без разметки /dev/sdc

На всех хостах должен стоять docker, а настройка и управление идет уже через управляющую ноду (к доп нодам подключаемся только для настройки докера)

Установка Docker
apt install docker.io -y
mkdir -p /etc/docker
nano /etc/docker/daemon.json

{
  "storage-driver": "overlay2",
  "log-driver": "json-file",
  "log-opts": {
     "max-size": "10m",
     "max-file": "3"
  },
  "default-ulimits": {
    "nofile": {
      "Name": "nofile",
      "Hard": 262144,
      "Soft": 262144
    }
  },
  "default-address-pools": [
    {
      "base": "172.17.0.0/16",
      "size": 24
    }
  ]
}

systemctl restart docker

ceph orch daemon add osd ceph-node2:/dev/sdc

### CephFS ###
Создадим файловую систему, которую можно будет примонтировать на клиенте. Для этого сначала необходимо:

Развернуть демон метаданных (mds).
cs
ceph orch apply mds cms_data --placement="ceph-node1 ceph-node2 ceph-node3"
ceph orch apply mds graf_data --placement="ceph-node1 ceph-node2 ceph-node3"
ceph orch ps | grep mds

Создать новый логический пул.
ceph osd pool create cephfs_cms_data 32
ceph osd pool create cephfs_graf_data 32
ceph osd pool create cephfs_cms_metadata 16
ceph osd pool create cephfs_graf_metadata 16

ceph fs status
ceph mds stat
ceph orch ps --daemon-type mds

Создать файловую систему CephFS.
ceph fs new cms_data cephfs_cms_metadata cephfs_cms_data
ceph fs new graf_data cephfs_graf_metadata cephfs_graf_data

ceph fs ls

На web-node1 создаем
* с содержимым из файла ceph.client.admin.keyring.
nano /etc/ceph/ceph.keyring

* с содержимым из файла ceph.conf.
nano  /etc/ceph/ceph.conf

* содержимое файла ceph.client.admin.keyring (только то, что идет после key =).
nano /etc/ceph/admin.secret

Создаем каталог, в который будем монтировать файловую систему ceph:

mount -t ceph 10.20.30.48:6789,10.20.30.49:6789,10.20.30.50:6789:/ /opt/cms/data -o name=admin,secretfile=/etc/ceph/admin.secret,fs=cms_data
